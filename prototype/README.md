# 序 · 个人工作台交互原型

这是用于讨论信息布局与操作路径的临时 UI 原型，依据 [个人工作台需求文档 v0.6](../docs/个人工作台需求文档.md) 制作。正式产品尚未实现，所有人员、来源编号、提交版本和产线反馈均为虚构。

原型要回答的问题：**个人今日行动与三条产线的偏差，如何共同呈现，才能让用户快速决定先做什么、跟进什么、协调什么？**

## 启动与预览

在项目根目录运行（仅需 Python 3，无第三方依赖）：

```powershell
python prototype/serve.py
```

访问 `http://127.0.0.1:8765/?variant=A`。服务仅监听本机；按 `Ctrl+C` 停止。端口被占用时可用 `python prototype/serve.py --port 8766`。

也可以直接双击 `index.html` 预览。使用本机 HTTP 服务时，浏览器剪贴板权限行为更可预测。复制失败会显示手工复制入口，不会误报成功。

底部浮动条切换 A/B/C，也支持左右方向键。编辑输入框、选择框、可编辑内容或打开对话框时，方向键不切换布局。URL 的 `variant` 参数保留布局，`view` 参数可直达页面。

| 参数 | 页面 |
| --- | --- |
| `view=today` | 今日 |
| `view=tasks` | 个人任务及其 MR 专项筛选 |
| `view=manage` | 产线管理 / 其他管理事项 |
| `view=review` | 周月回顾 |
| `view=prompts` | 提示词库 |
| `view=executions` | AI 执行记录 |
| `view=settings` | 模型配置、来源与同步、数据说明 |

## 三种方案

| 方案 | 信息组织 | 适合验证什么 | 取舍 |
| --- | --- | --- | --- |
| A · 今日驾驶舱 | 深墨绿色左侧导航；专注与今日任务通栏展示，长期事项、跟进与回顾紧凑排列，产线本周独立置于底部 | 本人研发行动与管理异常能否并行照顾 | 综合信息较多，需要控制首屏密度 |
| B · 行动清单 | 顶部导航；行动、等待、新变化三栏；产线摘要在下 | 能否用较少视觉干扰快速处理个人行动 | 产线信息优先级比 A 低 |
| C · 周计划板 | 深色紧凑导航；工作日计划列；产线承诺在下 | 是否更习惯按计划日期理解一周工作 | 窄屏需横向滑动周计划；不包含时间块或日历拖拽 |

**建议先评审 A。** 它同时保留需求中的两条主线；B 与 C 用于比较个人行动密度与周视角的价值。这是设计建议，尚未经用户选择或正式使用验证。

固定演示日为 **2026年11月06日**，周范围 **11月02日—11月08日**，时区 **Asia/Shanghai**。这里展示的是需求文档对应的演示周期，不随系统当前日期变化。

## 可体验的操作

1. 今日点击任务查看抽屉，修改下一步、安排今日或移到明日；个人计划与来源截止分别显示。完成个人行动后，来源状态和验证结论保持独立。
2. 快速记录只填写标题，进入个人任务收件箱；选择“管理”则进入其他管理事项。搜索支持标题、编号和项目，另有来源、项目、类型筛选。
3. 在个人任务切到 MR 评审，按本人评审进展、项目和作者筛选；比较当前提交与已检查版本。已合并仍可能待复查；记录已检查当前版本也不会自动结束评审或写入 GitLab。
4. PingCode 任务详情进入“准备回写”，查看目标、原值、新值和选定评论；切换成功、冲突、响应丢失三种模拟场景。冲突保留草稿，响应丢失显示待核实，模拟成功后禁止重复提交同次请求。
5. 查看同步详情，模拟 GitLab 断连，核对 PingCode 和本地计划仍然保留。设置中的定时拉取开关只展示暂停状态，不启动后台调度。
6. 管理切换月、周重点，记录反馈，回到今日查看共享反馈；结转要求填写原因，保留原周期未完成事实。关联任务打开同一份任务状态，协调完成不自动关闭风险。
7. 提示词支持新建、编辑、临时保存、搜索、复制与填入 AI 指令。复制使用最近保存的正文；未保存离开需选择保留或放弃。Windows 系统剪贴板可能把 LF 规范化为 CRLF，正文缩进、空行、特殊字符和占位符保留。
8. 回顾勾选事实，生成**预置规则拼接的演示草稿**，人工编辑、复制或下载 Markdown。草稿保留来源编号，排除敏感人员记录；不是模型生成结果。
9. 新建 AI 演示计划，选择材料，查看范围后单次授权。演示正常流程、超范围暂停、部分失败、停止后续步骤。演示结束显示“未真实核验”，不会标为真实执行完成。
10. 设置提供本地部署、DeepSeek 官方 API、New API 三类配置的表单示意；不采集凭据，不真实检查连接，能力始终保持未验证。上游或材料许可不明确的外部配置不能用于内部材料演示计划。

底部 `ⓘ` 可查看当前布局、页面、今日任务、完成行动、待复查版本和最近操作，便于核对切换后的状态。

## 需求对应与边界

| 需求范围 | 本次原型呈现 | 不能据此认定完成的能力 |
| --- | --- | --- |
| P01—P04 | 汇总、搜索筛选、今日安排、下一步、验证区分、AI 基建示例 | 实际来源拉取、持久保存、真实效果评估 |
| P05—P09 | MR 视图、评审进展、版本复查、来源与个人状态分离 | 内网 GitLab 版本适配、真实同步与身份去重 |
| P10—P11 | 回写预览、冲突、待核实、单次模拟提交、独立同步提示 | API 回写、并发保护、幂等保障、真实重试与调度 |
| M01—M06 | 三产线月周目标、反馈、关联行动、风险、结转记录 | 正式产线资料、结果验收、完整历史存储与风险关闭流程 |
| M07—M08 | 共用管理任务、敏感记录隐藏、总结材料跟进 | 正式周期生成、存储保护、人员或招聘业务系统 |
| S01—S07 | 跟进摘要、周月材料、来源说明、导出、时区与资料边界 | 后台提醒、备份恢复、跨会话保存、内网连接与保护措施 |
| S08—S12 | 可选拆解建议、回顾草稿、提示词编辑复制 | 真实模型调用、跨会话提示词保存、AI 生成质量验收 |
| S13—S16 | 三类模型配置示意、单次执行计划、范围、步骤和异常 | 真实模型和工具闭环、权限执行器、真实产物与回执核验 |

本原型使用内存状态，刷新、关闭重开会重置；无数据库、无本地存储、无持久化。下载 Markdown 和写入剪贴板是用户主动触发的本机浏览器操作。没有任何网络业务请求，不读取内部资料或真实账号。

## 文件与检查证据

- `index.html`：独立原型入口。
- `styles.css`：三种结构布局、组件与响应式显示。
- `app.js`：虚构数据、页面呈现与内存交互。
- `serve.py`：仅监听 `127.0.0.1` 的本地静态服务器。
- `screenshots/`：浏览器截图，包含三方案、窄屏与主要子页面。
- `verification-results.json`：浏览器交互检查的逐项结果。
- `verification.md`：验证范围、命令、已知限制与交接说明。

当前目录不是 Git 仓库，本次没有初始化仓库或创建提交。三种方案均作为独立临时原型保留；方案选择尚待用户评审，不宣称形成已验证设计决策。后续进入正式开发时重新实现已确认的交互，并补齐真实数据、存储、权限和接口验证；不直接将原型当作生产代码发布。
