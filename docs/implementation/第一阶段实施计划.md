# Personal Workbench Phase 1 Implementation Plan

> 历史第一阶段计划。用户随后追加完整首版持续实施授权，当前阶段状态由《完整首版实施计划》《需求追溯》《验证记录》维护；以下保留最初任务划分，未勾选不代表对应功能被删减。实际目录已按模块合理调整。

**Goal:** 交付方案 A 的可靠本地任务与提示词闭环，为第二阶段 Linux 后台部署保留相同接口。

**Architecture:** React 浏览器访问同源 Fastify API。SQLite 事务提交后响应成功；凭据存储与业务备份分离；来源与 AI 在实际接入前明确标记未实现。

**Tech Stack:** Node.js 24、TypeScript、React、Vite、Fastify、better-sqlite3、Zod、Vitest、Playwright。

**Spec:** `docs/implementation/技术方案.md`，需求 v0.7。

## Global Constraints

- 不改需求/原型基线，不伪造同步、模型、产物或核验结果；不发送真实公司资料。
- 默认 localhost；远程部署显式配置、认证和 HTTPS，第二阶段实际验证。
- UTF-8，无明文凭据进入代码/日志/备份；敏感正文默认拒绝保存。
- 每项变更先运行行为失败测试，再实现；配置和纯文档仅做对应校验。
