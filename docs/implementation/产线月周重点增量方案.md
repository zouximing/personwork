**目标**：在已有 line／period／risk／review 上增量实现三线概览、单线月周管理、周对比、结转、周期提醒、风险预警及周报独立成节。

**方案选择**：沿用已有文档持久化和修订保护，新增共享纯计算模块与小型产线视图。相比另建一套月周实体，能保持现有任务关联、来源保护和历史；相比仅增加前端字段，能保证批量操作、月末事实和周报快照由后台验证。

**文件边界**：`packages/contracts/src/management.ts` 字段与校验；新增 `production.ts` 统计、周期、对比和预警；`apps/server/src/management.ts` 批量结转、周期汇总、周报快照、路由；`app.ts` 周期调度；`backup-validation.ts` 新约束；`pages/Management.tsx` 与产线组件维护、总览和首页摘要；`styles.css` 响应式；测试和追溯文档。其他个人任务、来源、模型、原型不改业务行为。

**数据**：period增加completion／notes／progressStatus，line增加reminderWeekday，risk增加level／targetCloseDate／escalated。旧记录读取补默认值，PATCH不重置省略字段。周进展与旧阶段状态通过后台规范化保持一致。月末汇总保存为追加事件，不增加数据库表。周报产线节直接并入可编辑正文／旧格式进展节，并记录对应事实ID用于差异和隐私检查。

**关键边界**：月完成率排除取消项；周完成不联动月；重复结转检查先于旧修订拒绝以支持安全重试；新周期提示按每线是否已有对应周期重点判断；风险闭环必须保留现有结果与依据；周报资料后台自动收集且递归排除隐私；复制和发布仅使用已保存快照。
