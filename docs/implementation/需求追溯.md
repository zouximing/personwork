## 状态含义

2026-11-07 用户追加确认 GitLab 同步范围：本人负责的 Issue、本人 Assignee MR 与本人 Reviewer MR 合并去重后进入任务中心。Issue 与 MR 按对象类型隔离身份、编号及评审展示；未关闭事项不限历史天数，保留旧 MR 绑定／评审与本地安排。该增量映射 P01、P05、P07、P08、P09、S03、S04 及 AC05、AC16—AC19，证据为 `tests/sources.test.ts`、`tests/backup-integrity.test.ts`、`tests/management.test.ts`、`tests/e2e/gitlab-assignments.spec.ts`；本地验证不代表公司 GitLab 已验收。

“本地验证”表示代码及本机用例有证据，不代表正式用户验收；“适配待实接”表示真实 HTTP 适配逻辑经过 loopback 服务验证，公司实例／真实模型未验证；“部分／受阻”表示明确列出的能力没有通过门禁，不能对外宣称完成。测试仅使用 synthetic 数据，开发结果仍需用户人工复核。
